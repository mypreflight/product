# Launch plan

Where MyPreflight stands, what's left before launch, and how we'll measure the beta.

Last reviewed: 2026-10-20

## Status

Private beta. No outside users yet. Everything is free. All core features work end to end (sign-up, SimBrief import, briefing, Transponder tracking, post-flight, flight page, map history), tested by hand over about 60 completed flights. The remaining work is polish.

## Launch bar

No launch until the features are satisfying, onboarding exists, and top-level marketing materials are ready. A polished experience is how we stand out.

## Timeline

| When | What |
| --- | --- |
| Mid-December 2026 | Quiet open beta: small shares in Discords and Facebook groups to catch the Christmas flying crowd (simmers fly more over the holidays) |
| Christmas break | Fix what the beta finds; lots of development time |
| January 2027 | Full, polished launch |

The website says "late 2026" for the premiere; moving to early 2027 has no consequence.

Order of work: polish, then a round of first-user feedback, then new features.

## Before launch

- [ ] Onboarding
- [ ] Transponder download page
- [ ] Security audit (Oskar does it himself)
- [ ] UI polish: one consistent look across dozens of views, modals and components; high-value information shown well (e.g. cargo types and cold-chain details are currently shown poorly); mobile improvements in places; small, easy sign-up bugs
- [ ] Outstanding map history (faster) and flight page
- [ ] In-flight live view
- [ ] Licence change
- [ ] Marketing materials

## Onboarding flow

1. Sign up.
2. Import from SimBrief.
3. Get briefing materials right away and be impressed.
4. Trust us enough to download the Transponder.
5. Track a flight.

Trust on the first screens is critical: users have to run a local app on their sim PC, and without it half the tracking features are lost.

## Beta metrics

- Number of users
- Number of flights
- Number of Transponder connections

Funnel analysis (import → flight started → completed, and where users get stuck) and Hotjar-style UX analytics come later, in their own session.

## Feedback

GitHub issues and Discord. An in-app feedback system maybe later; it would slow development now.
